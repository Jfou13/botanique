# Familles botaniques

Ce dossier presente les principales familles representees dans le catalogue. Chaque page resume les caracteres utiles pour reconnaitre la famille et renvoie vers les plantes du depot qui en font partie.

## Vocabulaire

- **Famille :** groupe botanique situe au-dessus du genre dans la classification.
- **Genre :** groupe de plantes proches, dont le nom commence par une majuscule.
- **Espece :** unite botanique identifiee par un nom de genre et une epithete specifique.
- **Capitule :** inflorescence composee de nombreuses petites fleurs reunies comme une seule fleur.
