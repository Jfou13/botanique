# Photos

Les photos liees aux fiches sont stockees dans ce dossier.

## Nommer les fichiers

Utiliser le nom scientifique en minuscules, avec des tirets :

```text
nom-scientifique-01.jpg
nom-scientifique-feuille-01.jpg
nom-scientifique-fleur-01.jpg
```

## Conseils

- Garder une image d'ensemble et des details utiles a l'identification.
- Indiquer le credit et la licence sous chaque image dans la fiche.
- Compresser les photos avant de les ajouter si elles sont tres lourdes.
- Eviter de remplacer une photo existante : ajouter un nouveau numero.
